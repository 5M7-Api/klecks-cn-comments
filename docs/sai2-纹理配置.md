# SAI2 笔刷纹理（Texture）工作原理分析

## 现象

在 SAI2 中，如果给笔刷设置一个纹理（例如棋盘格、纸纹等），会发现一个很有趣的现象：

- 在画布不同位置分别画两笔。
- 即使两笔之间相隔很远。
- 即使使用不同的笔压（Pressure）。
- 两块纹理仍然能够**自然连续地拼接**，不会重新开始。

例如，一个棋盘格纹理：

```
■■□□■■□□■■□□
■■□□■■□□■■□□
□□■■□□■■□□■■
□□■■□□■■□□■■
```

第一笔画这里：

```
■■XX■■□□■■□□
■■XX■■□□■■□□
```

第二笔画这里：

```
■■□□■■XX■■□□
■■□□■■XX■■□□
```

两块纹理能够无缝连接。

---

## 最初的猜想

最容易想到的一种解释是：

> SAI2 会先把整张纹理铺满整个画布，然后每次画笔只是给这张纹理对应的位置填充颜色。

这种理解已经**非常接近真实实现**。

不过，从图形学角度来看，可以描述得更准确一些。

---

# 更准确的实现方式

SAI2 的 Texture 更像是：

> **固定在整个画布坐标系（World Space）中的一张无限平铺纹理。**

而不是：

> **每一笔拥有自己独立的纹理坐标。**

也就是说：

纹理坐标取决于：

```
画布坐标 (x, y)
```

而不是：

```
笔刷内部坐标 (u, v)
```

因此，无论什么时候画、画多少笔，只要画到同一个位置，取得的都是同一个纹理值。

---

# 为什么纹理能够连续？

假设纹理本身只有：

```
■■□□
■■□□
□□■■
□□■■
```

实际上程序不会真的生成无限大的图片。

更可能采用的是：

```
u = x mod textureWidth
v = y mod textureHeight
```

例如：

纹理宽度：

```
4
```

画布坐标：

```
(13, 7)
```

则：

```
u = 13 mod 4 = 1
v = 7 mod 4 = 3
```

于是始终采样：

```
texture[1][3]
```

因此，对于整个画布来说，相当于纹理无限重复：

```
■■□□■■□□■■□□
■■□□■■□□■■□□
□□■■□□■■□□■■
□□■■□□■■□□■■
```

但实际上并没有真正创建这样一张超大的图片。

---

# 笔压为什么不会影响纹理位置？

Pressure（笔压）通常只影响：

- 不透明度（Opacity）
- Flow（流量）
- Density（浓度）
- Brush Size（笔刷大小）
- Color Mixing（混色）

而不会影响：

```
纹理坐标
```

因此最终颜色更接近：

```
Final Color
=
Brush Color
× Pressure
× Opacity
× Texture(x, y)
```

注意：

这里的：

```
Texture(x, y)
```

是：

```
画布坐标
```

而不是：

```
Texture(Brush UV)
```

所以：

即使力度不同，

纹理仍然保持完全一致。

---

# "铺一张蒙版"这种理解正确吗？

可以认为：

> **逻辑上是正确的。**

可以把 Texture 理解成：

```
Texture Mask
```

例如：

```
100%
80%
40%
20%
90%
```

画笔真正做的是：

```
最终Alpha
=
Brush Alpha
× Texture Mask
```

或者：

```
最终浓度
=
Pressure
× Brush Density
× Texture
```

因此：

画笔其实只是决定：

> **哪些区域受到纹理影响。**

所以：

"画布先铺好纹理蒙版，再往里面填色"

这种理解虽然不是底层真正的数据结构，

但从效果来说几乎完全一致。

---

# 为什么很多软件不是这样？

例如：

- Photoshop
- Krita（部分笔刷）
- Clip Studio（部分模式）

很多采用的是：

```
Texture follows Brush
```

也就是：

每次落笔：

```
Brush UV
```

都会重新开始。

例如：

第一笔：

```
■■□□
■■□□
```

第二笔：

```
■■□□
■■□□
```

因此不同笔触之间不会自动连续。

这种方式更适合：

- 毛刷
- 喷枪
- 木纹
- 布纹

因为希望纹理跟着笔尖移动。

---

# 为什么 SAI2 要这样设计？

SAI 的 Texture 更多是在模拟：

- 纸纹（Paper）
- 水彩纸
- 素描纸
- 画布纹理（Canvas）

现实中的纸纹：

并不会随着画笔移动。

纸纹永远固定在纸上。

因此：

画笔只是：

```
在固定的纸纹上着色
```

而不是：

```
每画一笔重新生成纸纹
```

SAI2 的实现正是在模拟这种真实的绘画体验。

---

# 总结

SAI2 的 Texture 工作方式可以概括为：

- Texture 是固定在整个画布坐标系中的连续纹理。
- 每次绘制时，根据画布坐标实时采样纹理，而不是从笔刷重新开始贴图。
- Pressure（笔压）、Opacity（透明度）、Density（浓度）等只影响最终颜色或透明度，不影响纹理坐标。
- 程序通常不会真正生成一张覆盖整个画布的巨大纹理，而是在采样时通过 `x mod width`、`y mod height` 等方式实现无限平铺。
- 从逻辑效果来看，可以将其理解为："画布上始终铺着一张纹理蒙版，画笔只是对蒙版对应区域进行着色。"

---

# 一句话总结

> **SAI2 的 Texture 并不是属于笔刷，而是属于画布。画笔只是决定哪些位置受到这张固定纹理的影响，因此不同笔触之间能够天然保持纹理连续。**
